# Security policy

## Reporting a vulnerability or a trust violation

Report it privately through GitHub: **Security → Report a vulnerability** in this repository. Please do not open a public issue for something that could be exploited.

A trust violation, meaning any behaviour that contradicts [`docs/trust-model.md`](docs/trust-model.md) (a network connection, a write outside RosmarOps' folders, a secret shown in full, telemetry), is the most serious kind of bug in this product. Report it the same way.

Include, if you can: the RosmarOps version and the SHA-256 of the program you ran, what you observed, and how to reproduce it. Do not include real secrets.

## Supported versions

Only the latest release receives fixes.
