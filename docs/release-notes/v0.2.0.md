# RosmarOps v0.2.0

One program, one double click. Windows only.

## What's new
- No zip and no launchers: download `rosmarops.exe` and double-click it.
- The first time, it finds your projects on its own: the ones Claude Code knows, the ones you opened in Cursor or VS Code, and the usual folders in your user profile. If it finds none, it asks you to choose the folder where you keep them.
- The report opens in your Windows language (English or Spanish) and links to the other one. `--lang` still chooses it.
- It reads its configuration only from the `.rosmarops` folder in your user profile, never from the folder where you saved the program.
- A computer with only agents RosmarOps cannot evaluate yet (for example, GitHub Copilot or Cline) now says so, instead of «no AI agents found».

Everything in v0.1.0 is still there: see its release notes.

## Install
Download `rosmarops.exe` and double-click it.

If you used v0.1.0, RosmarOps keeps your configuration and history, and asks you to confirm the new version the first time. If you scheduled the weekly review, the report gives you the command to point it at the new program.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
```
Compare the SHA-256 with `SHA256SUMS.txt`. Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.2.0" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`.

## Known limits
- The program is not signed with a code-signing certificate, so Windows SmartScreen may warn you the first time. Check the attestation and the checksum first.
- Projects are found the first time only. To add projects later, add them to `repo_roots` in `config.json`; RosmarOps will ask you to confirm the change.
- The limits of v0.1.0 still apply.

See `docs/trust-model.md` for every claim and how to check it.
