# RosmarOps v0.11.4

v0.11.4 lets the Microsoft Store update RosmarOps without stopping your weekly check. If you downloaded RosmarOps from GitHub or winget, nothing changes for you.
- If you installed RosmarOps from the Microsoft Store, from now on it accepts the Store's updates without asking you, and the weekly check keeps running. Before, any new version made it stop and ask.
- It only accepts a new version if it comes from the RosmarOps package of the Microsoft Store, runs from the package's own folder and is newer than the one you had. Otherwise it asks you, as before, or shows a red report if nobody is at the computer.
- The report tells you when RosmarOps was updated through the Microsoft Store, and from which version.
- If your weekly check still runs an older copy you downloaded before, the report tells you and gives you the command to point it to the Microsoft Store version.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.11.4 (español)

La v0.11.4 deja que la Microsoft Store actualice RosmarOps sin parar tu revisión semanal. Si descargaste RosmarOps desde GitHub o winget, para ti no cambia nada.
- Si instalaste RosmarOps desde la Microsoft Store, a partir de ahora acepta las actualizaciones de la Store sin preguntarte, y la revisión semanal sigue funcionando. Antes, cualquier versión nueva hacía que se parara a preguntar.
- Solo acepta una versión nueva si viene del paquete de RosmarOps de la Microsoft Store, se ejecuta desde la carpeta del propio paquete y es más nueva que la que tenías. Si no, te pregunta, como antes, o muestra un informe en rojo si no hay nadie delante del ordenador.
- El informe te dice cuándo RosmarOps se ha actualizado desde la Microsoft Store, y desde qué versión.
- Si tu revisión semanal todavía ejecuta una copia anterior que descargaste antes, el informe te lo dice y te da la orden para que apunte a la versión de la Microsoft Store.

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- Linux y WSL, x86-64: `rosmarops-linux-amd64`
- Linux en ARM (por ejemplo, una Raspberry Pi o un servidor ARM): `rosmarops-linux-arm64`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.

¿No sabes qué Mac tienes? Menú Apple > Acerca de este Mac: «Chip» es Apple silicon; «Procesador» es Intel. `SHA256SUMS.txt` solo sirve para comprobar la descarga, y no necesitas «Source code» para usar RosmarOps. En Linux, dale permiso de ejecución primero con `chmod +x rosmarops-linux-amd64` y ejecútalo con `./rosmarops-linux-amd64`.
