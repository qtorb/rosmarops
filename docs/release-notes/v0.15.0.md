# RosmarOps v0.15.0

v0.15.0 adds usage statistics you can turn off, and a company mode for teams that manage their computers with Fleet. Update if you use 0.14.0 or an earlier version.
- Usage statistics: at the end of your first review, RosmarOps asks whether it may send a short summary after each review (version, system, how you installed it, the agents it found, the score, class and finding codes, and a random install id). Never paths, names, keys or the content of your settings. Turn it off at any time with `rosmarops usage off`; the last summary sent is in data/rosmarops-usage-last.json.
- Company mode: a company can install RosmarOps with its own configuration and read a short summary of each review through Fleet. The report says so in «Your company», and the company cannot hide findings from you.
- Weekly review: RosmarOps now recognises a weekly review set up for the whole computer (a global unit on Linux or a group task on Windows).

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.15.0 (español)

La v0.15.0 añade estadísticas de uso que puedes apagar y un modo empresa para equipos que gestionan sus ordenadores con Fleet. Actualiza si usas la 0.14.0 o una versión anterior.
- Estadísticas de uso: al final de tu primera revisión, RosmarOps te pregunta si puede enviar un resumen breve después de cada revisión (versión, sistema, cómo lo instalaste, los agentes que encuentra, la nota, la clase, los códigos de aviso y un identificador aleatorio). Nunca rutas, nombres, claves ni el contenido de tus ajustes. Se apaga cuando quieras con `rosmarops usage off`; el último resumen enviado está en data/rosmarops-usage-last.json.
- Modo empresa: una empresa puede instalar RosmarOps con su propia configuración y leer un resumen de cada revisión a través de Fleet. El informe lo dice en «Tu empresa», y la empresa no puede ocultarte avisos.
- Revisión semanal: RosmarOps reconoce ahora una revisión semanal configurada para todo el ordenador (una unidad global en Linux o una tarea de grupo en Windows).

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- Linux y WSL, x86-64: `rosmarops-linux-amd64`
- Linux en ARM (por ejemplo, una Raspberry Pi o un servidor ARM): `rosmarops-linux-arm64`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.
