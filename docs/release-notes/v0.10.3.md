# RosmarOps v0.10.3

v0.10.3 makes the report and your space say the same thing, and lets RosmarOps see instructions it was missing on a real computer. Update if you use 0.10.2 or an earlier version.
- When a key in git could be read by several agents, your space could show a different agent's before and after than the report («from 21 to 25» where the report said «from 8 to 9»). Both now come from the same calculation.
- On a real computer, GitHub Copilot, Antigravity CLI, Gemini CLI and Cline did not get their project's instruction files (AGENTS.md, or GEMINI.md for Gemini CLI) or their skills. They now do, as the reference computer already showed.
- New findings may appear because of that: «Copilot can rewrite its own instructions», and the same for Antigravity CLI and Cline. Agents that can write in your projects, like Claude Code, Codex or Cursor, may also show more findings of the kind «can rewrite another agent's instructions».
- The Copilot that comes with VS Code is now detected even with its default settings. If you turned off VS Code's AI features (`chat.disableAIFeatures`), it is not counted.
- With several Cline versions installed, RosmarOps now reads the newest one (for example 4.10 over 4.9).
- Your results are checked against their format before they leave your computer. If they don't pass, nothing is sent.
- The documentation now says where the log of what was sent to your space really is: in the `data` folder inside your reports folder.
- Every version is now tested on a complete invented computer on Windows, macOS and Linux, and nothing can be merged unless those tests pass.
- Your score may go down after updating. It counts what was missing before. In most cases it is a few points. If Copilot or Antigravity CLI is your only agent and there is an AGENTS.md it can change, it can go from 99 to 76, from «Contained» to «Open gaps». These findings never make a computer «Exposed» on their own.
- Known limit: RosmarOps still does not warn when GitHub Copilot, Gemini CLI, Cline or Antigravity CLI load an external MCP server from the catalog. It does for the other five agents.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.10.3 (español)

La v0.10.3 hace que el informe y tu espacio digan lo mismo, y permite a RosmarOps ver instrucciones que se le escapaban en un ordenador real. Actualiza si usas la 0.10.2 o una versión anterior.
- Cuando varios agentes podían leer una clave guardada en git, tu espacio podía mostrar el antes y el después de otro agente distinto al del informe («de 21 a 25» donde el informe decía «de 8 a 9»). Ahora los dos salen del mismo cálculo.
- En un ordenador real, GitHub Copilot, Antigravity CLI, Gemini CLI y Cline no recibían los ficheros de instrucciones de su proyecto (AGENTS.md, o GEMINI.md en Gemini CLI) ni sus skills. Ahora sí, como ya mostraba el ordenador de referencia.
- Por eso pueden aparecer avisos nuevos: «Copilot puede reescribir sus propias instrucciones», y lo mismo para Antigravity CLI y Cline. Los agentes que pueden escribir en tus proyectos, como Claude Code, Codex o Cursor, pueden mostrar también más avisos del tipo «puede reescribir las instrucciones de otro agente».
- El Copilot que viene con VS Code se detecta ahora aunque tenga los ajustes de serie. Si apagaste las funciones de IA de VS Code (`chat.disableAIFeatures`), no se cuenta.
- Con varias versiones de Cline instaladas, RosmarOps lee ahora la más nueva (por ejemplo, la 4.10 antes que la 4.9).
- Tus resultados se comprueban contra su formato antes de salir de tu ordenador. Si no pasan, no se envía nada.
- La documentación dice ahora dónde está de verdad el registro de lo que se ha enviado a tu espacio: en la carpeta `data`, dentro de tu carpeta de informes.
- Cada versión se prueba ahora en un ordenador inventado completo, en Windows, macOS y Linux, y nada se puede fusionar si esas pruebas no pasan.
- Tu nota puede bajar al actualizar, porque ahora cuenta lo que antes se escapaba. En la mayoría de los casos son unos pocos puntos. Si Copilot o Antigravity CLI es tu único agente y hay un AGENTS.md que puede cambiar, puede pasar de 99 a 76, de «Contenido» a «Huecos abiertos». Estos avisos nunca dejan un ordenador en «Expuesto» por sí solos.
- Límite conocido: RosmarOps todavía no avisa cuando GitHub Copilot, Gemini CLI, Cline o Antigravity CLI cargan un servidor MCP externo del catálogo. Sí lo hace con los otros cinco agentes.
