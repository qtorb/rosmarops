# RosmarOps v0.6.3

Setting up your online space no longer needs a terminal on Windows. You create your key on the web, and RosmarOps finds it by itself the next time you open it. The space is a private beta, by invitation only for now.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

## What's new
- Your key, without a terminal (Windows). If this computer has no key for your online space yet, double-clicking RosmarOps looks in your Downloads folder for your key file, named rosmarops-kit-<8 characters>.json. If it finds one, a window asks for your secret phrase once. RosmarOps reads only that file, never deletes it and never writes to Downloads. If you choose «Not now», the check runs as usual.
- Your results file, ready to drag. When a check ends on a computer with a key, a folder opens with your results file already selected, so you can drag it into your space.
- The «Your space» section of the report now tells you which file to drag.

On a Mac, the key is still added with `rosmarops kit import` in a terminal.

Everything in v0.6.2 is still there. The score method is still index 4.

## Install
Windows: download `rosmarops.exe` and double-click it. If you used an earlier version, RosmarOps asks you to confirm the new version the first time.

macOS (preview): follow «Install and run (macOS, preview)» in the README.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
gh attestation verify rosmarops-macos-apple-silicon --repo qtorb/rosmarops
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```
Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.6.3" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`; for macOS, the same with `GOOS=darwin GOARCH=arm64` or `GOARCH=amd64`. The sample reports are not in `SHA256SUMS.txt`: they are examples, not programs.

## Known limits
- The online space is a private beta, by invitation only.
- On a Mac, the key is added from a terminal.
- The limits of v0.6.2 still apply.

See `docs/trust-model.md` for every claim and how to check it.
