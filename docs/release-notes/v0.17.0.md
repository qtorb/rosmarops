# RosmarOps v0.17.0

v0.17.0 adds agent orchestrators: programs that launch several AI agents at once. RosmarOps now tells you which agents they can put to work without asking you, and what those agents can reach.
- Paperclip: RosmarOps finds it and tells you when it can put an agent such as Claude Code to work without asking you, when your version has a known serious security flaw, when it listens beyond this computer, and when anyone who reaches it can create an account. It never opens Paperclip's database or its secret files: it knows them by their path.
- Paseo and Claude Squad: RosmarOps reads, from their own files, the mode each agent is launched in.
- Orca: it launches agents with full access by default. RosmarOps can't read your own choice, which Orca keeps in a database it doesn't open, so the report says it assumes the default.
- Claude Code subagents: RosmarOps reads only the header of each subagent and tells you when one works without asking you, runs a command of its own, connects to MCP servers defined in its file, or can use every tool. Subagents in your user folder run in every project without the folder-trust question, and the report says so.
- Your score can change: the score index moves to version 6 and counts three of the four subagent findings. A subagent that can use every tool is shown but doesn't lower your score.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.17.0 (español)

La v0.17.0 añade los orquestadores de agentes: programas que lanzan varios agentes de IA a la vez. RosmarOps te dice ahora qué agentes pueden poner a trabajar sin preguntarte y a qué llegan esos agentes.
- Paperclip: RosmarOps lo encuentra y te avisa cuando puede poner a trabajar a un agente como Claude Code sin preguntarte, cuando tu versión tiene un fallo de seguridad grave conocido, cuando escucha fuera de este ordenador y cuando cualquiera que llegue a él puede crearse una cuenta. Nunca abre la base de datos de Paperclip ni sus ficheros secretos: los conoce por su ruta.
- Paseo y Claude Squad: RosmarOps lee, de sus propios ficheros, el modo con el que lanzan cada agente.
- Orca: de fábrica lanza los agentes con acceso completo. RosmarOps no puede leer lo que hayas elegido tú, que Orca guarda en una base de datos que no abre, así que el informe dice que supone el valor de fábrica.
- Subagentes de Claude Code: RosmarOps lee solo la cabecera de cada subagente y te avisa cuando uno trabaja sin preguntarte, ejecuta un comando propio, se conecta a servidores MCP definidos en su fichero o puede usar todas las herramientas. Los subagentes de tu carpeta de usuario funcionan en todos los proyectos sin la pregunta de confianza de la carpeta, y el informe lo dice.
- Tu nota puede cambiar: el índice de la nota pasa a la versión 6 y cuenta tres de los cuatro avisos de subagentes. Un subagente que puede usar todas las herramientas se enseña, pero no baja tu nota.
