# RosmarOps v0.3.0

More agents detected. Windows only.

## What's new
- Detects four more agents, without a score yet: Codex, Antigravity, Hermes Agent and Claude Desktop.
- Reads the keys they keep in plain files (Codex's `auth.json`, Hermes Agent's `.env` files, and the MCP servers of Antigravity and Claude Desktop), so the report shows which of your other agents can read them.
- Shows when Claude Code or Cursor can rewrite another agent's instructions, such as the `AGENTS.md` that Codex reads.
- The tests now also run on Windows on every change.

Everything in v0.2.0 is still there.

## Install
Download `rosmarops.exe` and double-click it. If you used an earlier version, RosmarOps asks you to confirm the new version the first time.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
```
Compare the SHA-256 with `SHA256SUMS.txt`. Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.3.0" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`.

## Known limits
- Codex, Antigravity, Hermes Agent and Claude Desktop are detected, not evaluated: RosmarOps does not read their approval or sandbox settings yet.
- Claude Desktop installed from the Microsoft Store keeps its configuration in another folder, which is not read yet.
- The limits of v0.2.0 still apply.

See `docs/trust-model.md` for every claim and how to check it.
