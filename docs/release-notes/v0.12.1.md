# RosmarOps v0.12.1

v0.12.1 corrects how RosmarOps reads agents where another AI model, or nobody, decides what the terminal runs. If you chose one of these modes, your score may go down. Update if you use 0.12.0 or an earlier version.
- Antigravity CLI in «Auto» or always-proceed, GitHub Copilot in «assisted» or with every tool allowed, and Gemini CLI with terminal commands allowed: when the terminal can run commands across your computer without asking you, RosmarOps now counts that those commands can read your keys outside the project. In most cases the score goes down to red.
- An agent now counts as able to send data out whenever its «Sending out» row says nobody or another model decides, whatever its mode is called.
- Antigravity CLI: if you haven't chosen a mode, the rows that depend on it carry an asterisk. Its changelog says the default mode changed to «Auto» in version 1.5.7; its documentation still says it asks you first. RosmarOps can't read which version you have.
- On macOS and Linux you can now install it with Homebrew: `brew install qtorb/rosmarops/rosmarops`.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.12.1 (español)

La v0.12.1 corrige cómo lee RosmarOps los agentes en los que otro modelo de IA, o nadie, decide lo que ejecuta la terminal. Si elegiste uno de esos modos, tu nota puede bajar. Actualiza si usas la 0.12.0 o una versión anterior.
- Antigravity CLI en «Auto» o always-proceed, GitHub Copilot en «assisted» o con todas las herramientas permitidas, y Gemini CLI con las órdenes de terminal permitidas: cuando la terminal puede ejecutar órdenes en todo tu ordenador sin preguntarte, RosmarOps cuenta ahora que esas órdenes pueden leer tus claves fuera del proyecto. En la mayoría de casos la nota baja a rojo.
- Un agente cuenta ahora como capaz de enviar datos fuera siempre que su fila «Enviar fuera» diga que no decide nadie o que decide otro modelo, se llame como se llame su modo.
- Antigravity CLI: si no has elegido modo, las filas que dependen de él llevan un asterisco. Su registro de cambios dice que el modo de serie pasó a «Auto» en la versión 1.5.7; su documentación sigue diciendo que te pregunta antes. RosmarOps no puede leer qué versión tienes.
- En macOS y Linux ya se puede instalar con Homebrew: `brew install qtorb/rosmarops/rosmarops`.
