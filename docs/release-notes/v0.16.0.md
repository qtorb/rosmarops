# RosmarOps v0.16.0

v0.16.0 brings a clearer report and fixes what our Linux testers ran into when updating. Update if you use 0.15.0 or an earlier version.
- A new first screen: the report now opens in three blocks, your result, your findings grouped by problem, and how to stop them coming back. A long list of findings becomes a short list of problems.
- Updating: when RosmarOps changes, every command now asks you in your language whether you installed the new version, instead of stopping with a message in English. If RosmarOps has to start from scratch, it tells you first that the computer will show up as a new one in your space.
- Linux: reports are now saved in ~/RosmarOps, a visible folder, so Firefox installed from Ubuntu's store can open them. Your earlier reports are moved there once.
- A review no longer ends asking you to pick findings by number. To dismiss or accept findings, run `rosmarops findings`.
- When a project takes too long to review, the report says «at least N findings» and how many projects were not finished.
- Cursor on Linux: RosmarOps also reads the company hooks file and the CLI settings where Cursor itself looks for them.
- Problem reports you choose to send now include the agent's name and your system version, as their format always intended.
- Before publishing, every version is now tested by installing it from scratch and by updating from the previous one, on Windows, macOS and Ubuntu.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.16.0 (español)

La v0.16.0 trae un informe más claro y arregla lo que encontraron nuestros probadores de Linux al actualizar. Actualiza si usas la 0.15.0 o una versión anterior.
- Una primera pantalla nueva: el informe se abre en tres bloques, tu resultado, tus avisos agrupados por problema y cómo evitar que vuelvan. Una lista larga de avisos pasa a ser una lista corta de problemas.
- Al actualizar: cuando RosmarOps cambia, todas las órdenes te preguntan en tu idioma si has instalado tú la versión nueva, en lugar de pararse con un mensaje en inglés. Si RosmarOps tiene que empezar de cero, antes te avisa de que el ordenador aparecerá como uno nuevo en tu espacio.
- Linux: los informes se guardan ahora en ~/RosmarOps, una carpeta visible, para que el Firefox que instala la tienda de Ubuntu pueda abrirlos. Tus informes anteriores se mueven allí una vez.
- Una revisión ya no termina pidiéndote que elijas avisos por número. Para descartar o asumir avisos, ejecuta `rosmarops findings`.
- Cuando un proyecto tarda demasiado en revisarse, el informe dice «al menos N avisos» y cuántos proyectos no terminaron.
- Cursor en Linux: RosmarOps lee también el fichero de hooks de empresa y los ajustes de la línea de órdenes donde los busca el propio Cursor.
- Los informes de problemas que decides enviar incluyen ahora el nombre del agente y la versión de tu sistema, como su formato preveía.
- Antes de publicarse, cada versión se prueba ahora instalándola de cero y actualizando desde la anterior, en Windows, macOS y Ubuntu.
