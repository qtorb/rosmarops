# RosmarOps v0.1.0

Release candidate. Windows only.

RosmarOps reads the configuration of your AI coding agents on this computer and shows what each one can reach: which keys it can read without asking you, whether it can send them out and who decides that (you, another AI model, or nobody), and which agents can change another agent's configuration or instructions. It reads only, writes only to its own folders, and contains no networking code.

## What's in this version
- Evaluates Claude Code and Cursor, each with its own Agent Posture Score out of 100. Detects Cline, without a score yet.
- Visual report in English or Spanish, in three steps: your situation, the one thing to do today with the exact change, and what's left.
- Memory between runs: what is new, still observed or no longer observed.
- Keys saved in git, including in past commits, as findings of their own.
- Export for your AI: a text you can paste into your own agent so it helps you apply the changes, asking you at each step.

## Install
Download `rosmarops-windows-amd64.zip`, extract the whole zip and double-click `rosmarops-run.bat` (or `rosmarops-ejecutar.bat` for Spanish).

## Check the download
```
gh attestation verify rosmarops-windows-amd64.zip --repo qtorb/rosmarops
```
Compare the SHA-256 with `SHA256SUMS.txt`. Building this tag from a clean clone with Go 1.24.7 (`CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath`) gives the same `rosmarops.exe`.

## Known limits
- The program is not signed with a code-signing certificate, so Windows SmartScreen may warn you. Use the attestation and the checksum to check it.
- It reads configuration at rest: it does not see what an agent does while it runs, settings kept only inside an app's database or on a vendor's servers, or anything set only in one terminal session. The report states what it assumes and lists what it could not read.

See `docs/trust-model.md` for every claim and how to check it.
