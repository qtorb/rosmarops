# RosmarOps v0.6.0

RosmarOps now shows which services each AI agent is connected to, such as payments, code, email and documents, and warns you when an agent can act through them without asking you. The score method moves to index 4.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

## What's new
- What it's connected to. For each agent, the report lists the connected services RosmarOps recognises: the official MCP servers of Stripe, PayPal, Square, Shopify Checkout, Vercel, Cloudflare, Supabase, Slack, Gmail, Google Drive, Google Calendar, GitHub, Notion, Linear, Atlassian, Asana, Sentry and HubSpot. For each one it says what kind of service it is and who decides: it asks you first, another AI model decides, it doesn't ask you, or it's blocked.
- A new warning when an agent can act through a connected service without asking you:
  - moving money without asking you is red (20 points), and after asking you is yellow (6);
  - changing your infrastructure or your database without asking you is red (15);
  - sending messages, writing email drafts, or changing your code, documents, calendar, issues or customer records without asking you is yellow (8).
  If another AI model approves instead of you, it counts as not asking you. If the service is set up for all your projects, the weight is multiplied by 1.5. Each warning says what it means for you and what to change.
- Payment keys. RosmarOps now recognises PayPal, Square, Braintree and Adyen keys by the name of the variable that holds them. They count as medium-privilege keys, because the name doesn't tell a live key from a test one. Stripe live keys are still recognised by their prefix, as high.
- Score method: index 4. Only the weights above are new. The methodology page has the whole method.
- New `rosmarops kit` commands prepare for a private beta of an online space where you'll see all your computers together. You don't need them yet.

Everything in v0.5.2 is still there.

## Install
Windows: download `rosmarops.exe` and double-click it. If you used an earlier version, RosmarOps asks you to confirm the new version the first time.

macOS (preview): follow «Install and run (macOS, preview)» in the README.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
gh attestation verify rosmarops-macos-apple-silicon --repo qtorb/rosmarops
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```
Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.6.0" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`; for macOS, the same with `GOOS=darwin GOARCH=arm64` or `GOARCH=amd64`. The sample reports are not in `SHA256SUMS.txt`: they are examples, not programs.

## Known limits
- The first run with v0.6.0 is not comparable with the last one, because the score method changed. The report separates what changed on your computer from what changed in the method.
- Only the services in the list above get the new warning. Other MCP servers don't.
- The limits of v0.5.2 still apply.

See `docs/trust-model.md` for every claim and how to check it.
