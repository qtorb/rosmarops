# RosmarOps v0.11.5

v0.11.5 only interrupts you when something changes, and makes it easier to connect a computer to your space. Update if you use 0.11.4 or an earlier version.
- The weekly check only shows you a notification when something changed. If nothing changed, it doesn't interrupt you, and the report is written as always.
- An MCP server that now points somewhere else counts as a change.
- When you connect a computer to your space, RosmarOps shows you a code. If the page asks you for one, for example because you opened the sign-in email in another browser or on your phone, type it there.
- On Windows, the connection window shows the address to copy into your browser if it didn't open by itself.
- The 10 minutes to confirm the connection start when you press «Save to my space», not when the window appears.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.11.5 (español)

La v0.11.5 solo te interrumpe cuando algo cambia, y hace más fácil conectar un ordenador a tu espacio. Actualiza si usas la 0.11.4 o una versión anterior.
- La revisión semanal solo te muestra una notificación cuando algo ha cambiado. Si no ha cambiado nada, no te interrumpe, y el informe se escribe como siempre.
- Un servidor MCP que ahora apunta a otro sitio cuenta como un cambio.
- Cuando conectas un ordenador a tu espacio, RosmarOps te enseña un código. Si la página te lo pide, por ejemplo porque abriste el correo para entrar en otro navegador o en el móvil, escríbelo allí.
- En Windows, la ventana de conexión enseña la dirección para copiarla en tu navegador si no se ha abierto solo.
- Los 10 minutos para confirmar la conexión empiezan cuando pulsas «Guardar en mi espacio», no cuando aparece la ventana.

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- Linux y WSL, x86-64: `rosmarops-linux-amd64`
- Linux en ARM (por ejemplo, una Raspberry Pi o un servidor ARM): `rosmarops-linux-arm64`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.

¿No sabes qué Mac tienes? Menú Apple > Acerca de este Mac: «Chip» es Apple silicon; «Procesador» es Intel. `SHA256SUMS.txt` solo sirve para comprobar la descarga, y no necesitas «Source code» para usar RosmarOps. En Linux, dale permiso de ejecución primero con `chmod +x rosmarops-linux-amd64` y ejecútalo con `./rosmarops-linux-amd64`.
