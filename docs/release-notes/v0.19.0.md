# RosmarOps v0.19.0

v0.19.0 shows your orchestrators in one place, scores three more agents, and no longer takes Enter as a yes.
- Your orchestrators: when a program on your computer starts AI agents (Paperclip, Paseo, Claude Squad, Orca), the report has a new card that says which agents it starts, whether they still ask you before acting, and how RosmarOps knows it.
- Three more agents with a score: OpenCode, Kilo Code and Claude Desktop. Claude Desktop is now found on Linux too.
- Continue: RosmarOps finds it and reads its MCP servers, but gives it no score, because Continue is no longer maintained. The report says so.
- Cursor and Grok Build, more settings read: Cursor's command-line run mode, its sandbox and the sandbox's network policy; Grok Build's own hooks, its sandbox file and its system-wide files.
- Usage statistics: pressing Enter alone is no longer a yes. You type y or n; Enter alone leaves the question for the next check. The report no longer says «at the next check» when the question comes at the end of this one.
- A clearer report: the sections that explain, and ask nothing of you, are marked «To understand»; findings about keys carry a key tag; a new heading, «The detail, problem by problem», separates the summary from the steps; on a narrow screen the header takes two lines.
- Fix: a finding about an orchestrator or a subagent that you marked «Doesn't affect me» no longer counts in the score, like any other; one you marked «I accept it» shows its date.
- Fix, and ours to own: one of our tests was sending usage statistics from our build machines. It sent nothing from anyone's computer. Now only a published version can ask or send, and a build made from the source code never does.
- Your score can change: if you use OpenCode, Kilo Code or Claude Desktop, they now count; and Cursor's command-line mode and sandbox network are now read. The index stays at version 7.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.19.0 (español)

La v0.19.0 te enseña tus orquestadores en un solo sitio, pone nota a tres agentes más y deja de tomar Intro como un sí.
- Tus orquestadores: cuando un programa de tu ordenador arranca agentes de IA (Paperclip, Paseo, Claude Squad, Orca), el informe tiene una tarjeta nueva que dice qué agentes arranca, si te siguen preguntando antes de actuar y cómo lo sabe RosmarOps.
- Tres agentes más con nota: OpenCode, Kilo Code y Claude Desktop. Claude Desktop se encuentra ahora también en Linux.
- Continue: RosmarOps lo encuentra y lee sus servidores MCP, pero no le pone nota, porque Continue ya no se mantiene. El informe lo dice.
- Cursor y Grok Build, más ajustes leídos: de Cursor, el modo de ejecución de su línea de órdenes, su sandbox y la política de red del sandbox; de Grok Build, sus propios hooks, su fichero de sandbox y sus ficheros de sistema.
- Estadísticas de uso: pulsar solo Intro ya no es un sí. Escribes s o n; Intro solo deja la pregunta para la próxima revisión. El informe ya no dice «en la próxima revisión» cuando la pregunta llega al final de esta.
- Un informe más claro: las secciones que explican, y no te piden nada, llevan la marca «Para entender»; los avisos sobre claves llevan una etiqueta de clave; un título nuevo, «El detalle, problema a problema», separa el resumen de los pasos; en una pantalla estrecha, la cabecera ocupa dos líneas.
- Arreglo: un aviso de un orquestador o de un subagente que marcaste «No me afecta» ya no cuenta en la nota, como los demás; uno que marcaste «Lo asumo» lleva su fecha.
- Arreglo, y nos toca decirlo: una de nuestras pruebas enviaba estadísticas de uso desde nuestras máquinas de compilación. No envió nada del ordenador de nadie. Ahora solo una versión publicada puede preguntar o enviar, y una compilación hecha desde el código fuente no lo hace nunca.
- Tu nota puede cambiar: si usas OpenCode, Kilo Code o Claude Desktop, ahora cuentan; y de Cursor se leen ahora el modo de su línea de órdenes y la red del sandbox. El índice sigue en la versión 7.
