# RosmarOps v0.13.0

v0.13.0 adds sandbox templates you can measure, covers Cursor and Grok Bot better, and says when it is reviewing a test environment. Your score may change if you use Cursor, Grok Bot or Antigravity CLI. Update if you use 0.12.1 or an earlier version.
- «Profiles» are now called «templates»: a text you copy and paste into your agent, which shows you the change and asks before saving it.
- Claude Code and Grok Build on macOS and Linux get a new template, «Development with sandbox». RosmarOps measures it before you apply it: 99 green for Claude Code, 75 yellow for Grok Build. «Try it just this once» gives you the command to open the agent with the sandbox on for one session, without changing its settings.
- Cursor: RosmarOps can't read some of its settings, because they live inside the app. With a console, it now asks you up to four questions. What you answer appears in the report as «declared by you». If you don't answer, it assumes the least controlled case.
- Grok Bot: RosmarOps now reads its local setting (only `~/.grokbot/settings.json`, never its tokens) and asks you whether you use it.
- If an agent can write a file your computer runs later, such as your terminal's startup file, RosmarOps now counts it: what goes there will run outside its sandbox. Your score may go down.
- Antigravity CLI in «Auto»: the «Running» row now says who decides and whether it runs inside its sandbox.
- If RosmarOps runs inside a container, a virtual machine or Windows Sandbox, the report says «Review of a test environment» under its title.
- On macOS and Linux you can install it with Homebrew: `brew install qtorb/rosmarops/rosmarops`.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.13.0 (español)

La v0.13.0 trae plantillas con sandbox que puedes medir, cubre mejor Cursor y Grok Bot, y dice cuándo está revisando un entorno de pruebas. Tu nota puede cambiar si usas Cursor, Grok Bot o Antigravity CLI. Actualiza si usas la 0.12.1 o una versión anterior.
- Los «perfiles» pasan a llamarse «plantillas»: un texto que copias y le pegas a tu agente, que te enseña el cambio y te pregunta antes de guardarlo.
- Claude Code y Grok Build en macOS y Linux tienen una plantilla nueva, «Desarrollo con sandbox». RosmarOps la mide antes de que la apliques: 99, verde, en Claude Code; 75, amarillo, en Grok Build. «Probar solo esta vez» te da la orden para abrir el agente con el sandbox encendido durante una sesión, sin cambiar sus ajustes.
- Cursor: RosmarOps no puede leer algunos de sus ajustes, porque viven dentro de la aplicación. Con consola, ahora te hace hasta cuatro preguntas. Lo que contestes sale en el informe como «declarado por ti». Si no contestas, supone el caso que menos controla.
- Grok Bot: RosmarOps lee ahora su ajuste local (solo `~/.grokbot/settings.json`, nunca sus tokens) y te pregunta si lo usas.
- Si un agente puede escribir en un fichero que tu ordenador ejecuta más tarde, como el de arranque de tu terminal, RosmarOps ahora lo cuenta: lo que ponga ahí se ejecutará fuera de su sandbox. Tu nota puede bajar.
- Antigravity CLI en «Auto»: la fila «Ejecutar» dice ahora quién decide y si se ejecuta dentro de su sandbox.
- Si RosmarOps se ejecuta dentro de un contenedor, una máquina virtual o Windows Sandbox, el informe lo dice bajo el título: «Revisión de un entorno de pruebas».
- En macOS y Linux se puede instalar con Homebrew: `brew install qtorb/rosmarops/rosmarops`.
