# RosmarOps v0.9.0

v0.9.0 scores two more agents: GitHub Copilot in VS Code and the Antigravity command-line tool (CLI).
- GitHub Copilot in VS Code and the Antigravity CLI now get a score, like Claude Code, Cursor, Hermes Agent, Codex and Grok Build. On Windows, if a policy set by your organisation decides what Copilot may approve on its own, the report follows that policy, not your own settings.
- The Antigravity app and IDE, and GitHub Copilot in JetBrains IDEs, now show as detected: RosmarOps sees them but doesn't score them yet, because they keep their permissions where it can't read them.
- When another AI model decides for the agent whether an action can go ahead (Codex's auto-review, Antigravity's auto mode, Copilot's Assisted mode), the report says so: a model decides, not you.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.9.0 (español)

La v0.9.0 puntúa dos agentes más: GitHub Copilot en VS Code y la herramienta de línea de comandos (CLI) de Antigravity.
- GitHub Copilot en VS Code y el CLI de Antigravity ya tienen nota, como Claude Code, Cursor, Hermes Agent, Codex y Grok Build. En Windows, si una política de tu organización decide qué puede aprobar Copilot por su cuenta, el informe sigue esa política y no tus propios ajustes.
- La app y el IDE de Antigravity, y GitHub Copilot en los IDE de JetBrains, aparecen ahora como detectados: RosmarOps los ve, pero todavía no les pone nota, porque guardan sus permisos donde no puede leerlos.
- Cuando otro modelo de IA decide por el agente si una acción sigue adelante (la auto-revisión de Codex, el modo automático de Antigravity o el modo Assisted de Copilot), el informe lo dice: decide un modelo, no tú.
