# RosmarOps v0.5.1

A new check for project hooks, three more known malicious packages, and clearer file names for macOS.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

## What's new
- Project hooks that run a script of the project. When a project's `.claude/settings.json` or `.claude/settings.local.json` makes Claude Code run a file inside that same project (a hook, `statusLine` or `apiKeyHelper`), the report shows it in yellow, and in red if the file is larger than 1 MB. Opening such a project runs that script with your permissions. RosmarOps keeps only the file's path and size: it does not keep the command or open the file. This does not change any agent's score.
- Threat data 2026.10.29.1: three PyPI packages that pose as a Claude client (`claudeopusfile`, `claudeopuseni`, `claudeopusenifile`, with their exact versions), from OSV.
- macOS files are now called `rosmarops-macos-apple-silicon` and `rosmarops-macos-intel` (before: `rosmarops-darwin-arm64` and `rosmarops-darwin-amd64`).

Everything in v0.5.0 is still there.

## Install
Windows: download `rosmarops.exe` and double-click it. If you used an earlier version, RosmarOps asks you to confirm the new version the first time.

macOS (preview): follow «Install and run (macOS, preview)» in the README.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
gh attestation verify rosmarops-macos-apple-silicon --repo qtorb/rosmarops
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```
Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.5.1" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`; for macOS, the same with `GOOS=darwin GOARCH=arm64` or `GOARCH=amd64`.

## Known limits
- The first run of this version is not comparable with the last one, because the detection rules changed.
- The project-hook check reads Claude Code only. Gemini CLI, Cursor and VS Code project files that run commands are not checked yet.
- A project-hook finding and a known-malicious-package finding are not tracked between runs: each run shows them as not comparable.
- The limits of v0.5.0 still apply.

See `docs/trust-model.md` for every claim and how to check it.
