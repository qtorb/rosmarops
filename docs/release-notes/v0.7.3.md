# RosmarOps v0.7.3

v0.7.3 is the first weekly release: each Tuesday, what the Observatory found that week reaches the program.
- New threats: four npm packages that pose as MCP servers and send cloud credentials to a fixed address (MAL-2026-18486 to MAL-2026-18489) are now recognised. Threat data 2026.11.03.1.
- The time limit grows with your projects: 15 seconds per project, from 5 to 20 minutes. The window and the report say the limit, and the report says at the top if it was reached and how many projects were not checked.
- Each finding says, first thing, the file it was found in, so you can check it yourself.
- The report says when the agents' knowledge was last reviewed, and warns you when this program is more than 14 days old.
- rosmarops.exe has its own icon and shows its version in Properties. The analysis window says RosmarOps and what it is doing in its title; in Windows Terminal, the taskbar button shows the progress.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

# RosmarOps v0.7.3 (español)

La v0.7.3 es la primera versión semanal: cada martes, lo que el Observatorio encontró esa semana llega al programa.
- Amenazas nuevas: ahora reconoce cuatro paquetes npm que se hacen pasar por servidores MCP y envían las credenciales de la nube a una dirección fija (MAL-2026-18486 a MAL-2026-18489). Datos de amenazas 2026.11.03.1.
- El límite de tiempo crece con tus proyectos: 15 segundos por proyecto, de 5 a 20 minutos. La ventana y el informe dicen el límite, y el informe avisa arriba si se agotó y cuántos proyectos quedaron sin revisar.
- Cada hallazgo dice, lo primero, en qué archivo está, para que puedas comprobarlo tú.
- El informe dice cuándo se revisó por última vez el conocimiento de los agentes y te avisa si este programa tiene más de 14 días.
- rosmarops.exe tiene su propio icono y enseña su versión en Propiedades. La ventana del análisis dice RosmarOps y lo que está haciendo en su título; en Windows Terminal, el botón de la barra de tareas enseña el avance.

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.

¿No sabes qué Mac tienes? Menú Apple > Acerca de este Mac: «Chip» es Apple silicon; «Procesador» es Intel. `SHA256SUMS.txt` solo sirve para comprobar la descarga, y no necesitas «Source code» para usar RosmarOps.
