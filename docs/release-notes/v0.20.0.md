# RosmarOps v0.20.0

v0.20.0 is about your first five minutes: what the report says first, where to start, and a detail you can actually work through.
- A verdict first: the report opens with one sentence that says how things stand, and a card, «Start here», with the one thing to do first.
- What each problem means: every problem now says in one sentence what it means for you, before the steps.
- A table you can read: each problem carries the icon of its family (key, between agents, agent, MCP, orchestrator, subagent, project, desktop). When two or more of your agents can change other agents' settings, the table shows one row, not one per agent.
- A detail you can manage: only the first six problems are open; the rest are folded, one line each. Inside «between agents», each agent is one line with its findings grouped by type. Problems with the same title and the same level are one, with how many times; so are secrets with no known service and the same readers.
- Titles that say who: findings about your desktop and «Can act without you» now name the agent; a long list of apps becomes a number, with the list inside. When three or more of your agents share the same problem of their own, they are one row.
- Usage statistics, one clear question: after the first check, RosmarOps asks only whether you want to help, with what it would send and what it never sends. On Windows it asks in a window, where Enter alone does nothing; on macOS and Linux, in the terminal. If you answered in an earlier version, it asks once more, because the question changed.
- More exact for Codex and VS Code: Codex in read-only mode no longer counts as if it wrote to your projects. On Linux, RosmarOps now reads Copilot's and Claude Code's VS Code settings where VS Code keeps them, as it already did on Windows and macOS. On Linux and macOS, it also reads Codex's system-wide requirements file.
- Your score can change: a Codex set to read-only can score higher (one point on our test computer). On Linux, Copilot's and Claude Code's scores now follow your VS Code settings. No factory score changes. The index stays at version 7.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.20.0 (español)

La v0.20.0 va de tus primeros cinco minutos: qué dice el informe primero, por dónde empezar y un detalle que se puede recorrer de verdad.
- Primero, un veredicto: el informe abre con una frase que dice cómo estás y con una tarjeta, «Empieza por aquí», con lo primero que hay que hacer.
- Qué significa cada problema: cada problema dice ahora en una frase qué significa para ti, antes de los pasos.
- Una tabla que se lee: cada problema lleva el icono de su familia (clave, entre agentes, agente, MCP, orquestador, subagente, proyecto, escritorio). Cuando varios de tus agentes pueden cambiar la configuración de otros, la tabla enseña una sola fila, no una por agente.
- Un detalle que se puede gestionar: solo salen abiertos los seis primeros problemas; los demás van plegados, en una línea cada uno. Dentro de «entre agentes», cada agente es una línea, con sus avisos juntos por tipo. Los problemas con el mismo título y el mismo nivel son uno solo, con cuántas veces; también los secretos sin servicio conocido y con los mismos lectores.
- Títulos que dicen de quién hablan: los avisos de tu escritorio y «Puede actuar sin ti» nombran ahora al agente; una lista larga de aplicaciones pasa a ser un número, con la lista dentro. Cuando tres o más de tus agentes comparten el mismo problema propio, salen en una sola fila.
- Estadísticas de uso, una sola pregunta clara: después de la primera revisión, RosmarOps solo pregunta si quieres ayudar, con lo que enviaría y lo que no envía nunca. En Windows pregunta en una ventana, donde Intro solo no hace nada; en macOS y Linux, en el terminal. Si ya contestaste en una versión anterior, pregunta una vez más, porque la pregunta ha cambiado.
- Más exacto con Codex y VS Code: Codex en modo de solo lectura ya no cuenta como si escribiera en tus proyectos. En Linux, RosmarOps lee ahora los ajustes de VS Code de Copilot y de Claude Code donde VS Code los guarda, como ya hacía en Windows y macOS. En Linux y macOS, también lee el fichero de requisitos de sistema de Codex.
- Tu nota puede cambiar: un Codex puesto en solo lectura puede subir de nota (un punto en nuestro ordenador de pruebas). En Linux, las notas de Copilot y de Claude Code siguen ahora tus ajustes de VS Code. No cambia ninguna nota de fábrica. El índice sigue en la versión 7.
