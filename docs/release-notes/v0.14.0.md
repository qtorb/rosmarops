# RosmarOps v0.14.0

v0.14.0 tells you which agents can act without you, fixes the Claude Code sandbox template, and brings RosmarOps into Claude Code as a plugin. Your score may go down if an agent can be woken up from outside. Update if you use 0.13.0 or an earlier version, and especially if you applied the Claude Code sandbox template.
- New: «Can act without you». If an agent can be woken up from outside (a chat such as Telegram or Discord, a Claude Code channel, or tasks that run on their own) and can do things without asking you, the report says so, and says who can give it orders: only you, a list of people, or anyone admitted to the chat. Your score may go down.
- Agent memory: RosmarOps now counts an agent's memory files and who can write them. It never opens them.
- Claude Code sandbox template: it is now a single text. With current versions of Claude Code, the second text we gave you for each project stopped the terminal from reading the project itself. If you pasted it into a project's `.claude/settings.json`, remove that block; the report tells you in which project.
- RosmarOps for Claude Code: a plugin that tells you in one line, when a session opens, what changed in what your agents can do. `/rosmarops` shows your latest result, also with the sandbox on. Install it in Claude Code with `/plugin install rosmarops --marketplace qtorb/rosmarops-claude-code`. It needs RosmarOps installed and does not use the network.
- Claude Code 2.1.325 and later ask before sandboxed commands unless a setting says otherwise. RosmarOps can't read your version, so it says what it assumes.
- Windows: the report says that RosmarOps doesn't look inside WSL or containers. If you use an agent there, run RosmarOps for Linux inside it too. Inside WSL, it warns that an agent can read your Windows drive under /mnt.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.14.0 (español)

La v0.14.0 te dice qué agentes pueden actuar sin ti, arregla la plantilla de sandbox de Claude Code y lleva RosmarOps dentro de Claude Code con un complemento. Tu nota puede bajar si un agente se puede despertar desde fuera. Actualiza si usas la 0.13.0 o una versión anterior, y sobre todo si aplicaste la plantilla de sandbox de Claude Code.
- Nuevo: «Puede actuar sin ti». Si a un agente se le puede despertar desde fuera y puede hacer cosas sin preguntarte, el informe lo dice, y también quién puede darle órdenes: solo tú, una lista de personas o cualquiera admitido en el chat. Se le puede despertar desde fuera con un chat como Telegram o Discord, con un canal de Claude Code o con tareas que se ejecutan solas. Tu nota puede bajar.
- Memoria de los agentes: RosmarOps cuenta ahora los ficheros de memoria de un agente y quién puede escribirlos. Nunca los abre.
- Plantilla de sandbox de Claude Code: ahora es un solo texto. Con las versiones actuales de Claude Code, el segundo texto que te dábamos para cada proyecto impedía a la terminal leer el propio proyecto. Si lo pegaste en el `.claude/settings.json` de un proyecto, quita ese bloque; el informe te dice en qué proyecto.
- RosmarOps para Claude Code: un complemento que, al abrir una sesión, te dice en una línea qué ha cambiado en lo que pueden hacer tus agentes. `/rosmarops` te enseña tu último resultado, también con el sandbox encendido. Instálalo en Claude Code con `/plugin install rosmarops --marketplace qtorb/rosmarops-claude-code`. Necesita RosmarOps instalado y no usa la red.
- Claude Code 2.1.325 y posteriores preguntan antes de ejecutar órdenes en el sandbox, salvo que un ajuste diga lo contrario. RosmarOps no puede leer tu versión, así que dice qué supone.
- Windows: el informe dice que RosmarOps no mira dentro de WSL ni de los contenedores. Si usas un agente ahí, ejecuta también RosmarOps para Linux dentro. Dentro de WSL, avisa de que un agente puede leer tu disco de Windows en /mnt.
