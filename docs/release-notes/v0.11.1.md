# RosmarOps v0.11.1

v0.11.1 fixes the weekly review on computers with many projects. Update if you use the weekly review.
- The weekly review could stop before finishing. The command RosmarOps gives you to schedule it set a 10-minute limit, but a check can take up to 20 minutes with many projects, so Windows stopped it. The command now allows 25 minutes. If you already have the weekly review, the report offers to update it.
- When RosmarOps is installed as a Windows package, the notification at the end of a scheduled review now appears under its own name. Before, it did not appear and the report opened instead.
- Built with Go 1.27.4, which fixes a vulnerability in Go's HTTP server (GO-2026-6859). RosmarOps only uses Go's HTTP client, so it was not affected; we update to keep the automatic security checks clean.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.11.1 (español)

La v0.11.1 arregla la revisión semanal en ordenadores con muchos proyectos. Actualiza si usas la revisión semanal.
- La revisión semanal podía pararse antes de acabar. La orden que te da RosmarOps para programarla le ponía un límite de 10 minutos, pero con muchos proyectos una revisión puede tardar hasta 20, y Windows la cortaba. Ahora la orden permite 25 minutos. Si ya tienes la revisión semanal, el informe te ofrece actualizarla.
- Cuando RosmarOps está instalado como paquete de Windows, la notificación al acabar una revisión programada sale ahora con su propio nombre. Antes no salía y se abría el informe.
- Compilado con Go 1.27.4, que corrige un fallo de seguridad en el servidor HTTP de Go (GO-2026-6859). RosmarOps solo usa el cliente HTTP de Go, así que no estaba afectado; actualizamos para que las comprobaciones automáticas de seguridad sigan limpias.

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- Linux y WSL, x86-64: `rosmarops-linux-amd64`
- Linux en ARM (por ejemplo, una Raspberry Pi o un servidor ARM): `rosmarops-linux-arm64`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.

¿No sabes qué Mac tienes?
