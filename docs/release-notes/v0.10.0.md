# RosmarOps v0.10.0

v0.10.0 scores two more agents, Gemini CLI and Cline, and shows when an agent can use apps on your desktop without asking.
- Gemini CLI and the Cline extension for VS Code now get a score. With Cline, RosmarOps now reads the folder where current versions keep their settings, so it also sees MCP servers it used to miss.
- If ChatGPT's or Codex's computer use is allowed to use an app without asking, the report says so: red if that app is a terminal, because that is the same as running commands without asking.
- The Cline command-line tool and Claude Desktop show as detected, not scored, and the report says why. Claude Desktop installed from the Microsoft Store is now read too.
- In the report, «Your space» now tells you the one step that saves your results: open RosmarOps again and click «Save to my space».
- Because of these new rules, your score may change after updating even if nothing changed on your computer.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.10.0 (español)

La v0.10.0 puntúa dos agentes más, Gemini CLI y Cline, y avisa cuando un agente puede usar aplicaciones de tu escritorio sin preguntarte.
- Gemini CLI y la extensión de Cline para VS Code ya tienen nota. Con Cline, RosmarOps lee ahora la carpeta donde las versiones actuales guardan sus ajustes, así que ve también servidores MCP que antes se le escapaban.
- Si el uso del ordenador de ChatGPT o de Codex puede usar una aplicación sin preguntarte, el informe lo dice: en rojo si esa aplicación es una terminal, porque es lo mismo que ejecutar comandos sin preguntarte.
- El CLI de Cline y Claude Desktop aparecen como detectados, sin nota, y el informe explica por qué. Ahora también se lee Claude Desktop instalado desde la Microsoft Store.
- En el informe, «Tu espacio» te dice el único paso que guarda tus resultados: vuelve a abrir RosmarOps y pulsa «Guardar en mi espacio».
- Por estas reglas nuevas, tu nota puede cambiar al actualizar aunque no haya cambiado nada en tu ordenador.
