# RosmarOps v0.10.2

v0.10.2 fixes several bugs that could leave a computer without a score, without its results in the space, or with a wrong result. Update if you use 0.9.0, 0.10.0 or 0.10.1.
- With the Cline extension's auto-approval settings saved, or with the Antigravity app or Copilot in JetBrains installed, the check could stop without a score and save nothing to your space. It now finishes.
- If ChatGPT's or Codex's computer use could use an app without asking, the new report could not be written. Fixed.
- A badly written configuration file of an agent no longer closes RosmarOps without a report: the problem is shown and the check continues.
- When a configuration file can't be read, the error no longer copies any of its text, so no key can end up in RosmarOps's own files.
- If git fails in a project, the report now says that project could not be checked, instead of showing it as clean.
- On Windows, Copilot, Antigravity CLI and Gemini CLI now see the keys of an MCP server inside a project.
- Built with a current version of Go, with its known security fixes, and checked for known vulnerabilities before publishing.
- Your score may change after updating: it now counts what was missing before.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.10.2 (español)

La v0.10.2 arregla varios fallos que podían dejar un ordenador sin nota, sin sus resultados en el espacio o con un resultado equivocado. Actualiza si usas la 0.9.0, la 0.10.0 o la 0.10.1.
- Con los ajustes de autoaprobación de la extensión de Cline guardados, o con la app de Antigravity o Copilot en JetBrains instalados, la revisión podía terminar sin nota y sin guardar nada en tu espacio. Ahora termina.
- Si el uso del ordenador de ChatGPT o de Codex podía usar una app sin preguntarte, el informe nuevo no se podía escribir. Arreglado.
- Un fichero de configuración mal escrito de un agente ya no cierra RosmarOps sin informe: el problema se muestra y la revisión sigue.
- Cuando un fichero de configuración no se puede leer, el error ya no copia nada de su texto, así que ninguna clave puede acabar en los ficheros del propio RosmarOps.
- Si git falla en un proyecto, el informe dice ahora que ese proyecto no se pudo revisar, en lugar de mostrarlo como limpio.
- En Windows, Copilot, Antigravity CLI y Gemini CLI ven ahora las claves de un servidor MCP dentro de un proyecto.
- Compilado con una versión actual de Go, con sus arreglos de seguridad conocidos, y comprobado contra vulnerabilidades conocidas antes de publicar.
- Tu nota puede cambiar al actualizar: ahora cuenta lo que antes se escapaba.
