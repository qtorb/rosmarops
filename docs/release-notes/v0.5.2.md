# RosmarOps v0.5.2

Hermes Agent now gets a score, RosmarOps reads Claude Code's login file, and each release comes with a sample report.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- `sample-report.en.html` and `sample-report.es.html`: a sample report (see below). You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

## What's new
- Hermes Agent is scored. RosmarOps uses what Hermes documents about its defaults: it can read and write almost any file and run commands on your computer without asking, and in its default `smart` mode another AI model only reviews commands that match a dangerous pattern. If you set `terminal.backend: docker` (or another isolated backend) in Hermes's `config.yaml`, RosmarOps counts Hermes as working inside that environment, not on your computer. The report suggests that setting as the fix.
- RosmarOps reads Claude Code's login file (`.claude\.credentials.json`) like other key files: it shows only the first and last four characters. An agent's own login file does not count against that agent, so Claude Code's score does not drop because you are signed in; it counts against the other agents that can read it.
- Hermes Agent's `SOUL.md` is read as its own instructions.
- Sample report: each release now includes a real report that this version produced on an invented computer (user, projects and keys are made up). It says so at the top.

Everything in v0.5.1 is still there.

## Install
Windows: download `rosmarops.exe` and double-click it. If you used an earlier version, RosmarOps asks you to confirm the new version the first time.

macOS (preview): follow «Install and run (macOS, preview)» in the README.

## Check the download
```
gh attestation verify rosmarops.exe --repo qtorb/rosmarops
gh attestation verify rosmarops-macos-apple-silicon --repo qtorb/rosmarops
shasum -a 256 -c --ignore-missing SHA256SUMS.txt
```
Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.5.2" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`; for macOS, the same with `GOOS=darwin GOARCH=arm64` or `GOARCH=amd64`. The sample reports are not in `SHA256SUMS.txt`: they are examples, not programs.

## Known limits
- The first run with Hermes Agent scored is not comparable with the last one, because the set of scored agents changed.
- Hermes: RosmarOps does not read its MCP token store, and a terminal backend it does not recognize counts as running on your computer (the report says so).
- The limits of v0.5.1 still apply.

See `docs/trust-model.md` for every claim and how to check it.
