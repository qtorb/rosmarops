# RosmarOps v0.11.3

v0.11.3 finds all your projects and shows you where each finding is. Update if you use 0.11.2 or an earlier version.
- RosmarOps now looks for your git projects in your whole user folder, up to 6 levels deep, on every check. Before, it only looked one level below a few folders with English names, and only the first time. The console says how many it found; the report lists them, and where it did not look and why.
- The search never enters hidden or system folders, links, other disks, network folders or cloud folders that are not on your computer. It only lists folder names: it never opens a file.
- A key that is only in your git history now says so: «… is in your git history», with the project, the commit and the file. Before, it showed the file as it is today, which git may be ignoring, and it looked like a false alarm.
- Where each finding is now shows in plain sight, in «What to do first» and in every row, not only under «Technical details».
- On macOS and Linux, the report no longer mentions %USERPROFILE% or Notepad.
- On Linux, if your browser is Firefox installed as a snap and can't open the report, the console tells you how to open it.
- If your system is in Catalan, Galician or Basque, RosmarOps now uses Spanish instead of English, on Windows and Linux.
- The notice about a repository with a long history appears at most once per check.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.11.3 (español)

La v0.11.3 encuentra todos tus proyectos y te enseña dónde está cada aviso. Actualiza si usas la 0.11.2 o una versión anterior.
- RosmarOps ahora busca tus proyectos de git en toda tu carpeta de usuario, hasta 6 niveles, en cada revisión. Antes solo miraba un nivel por debajo de unas pocas carpetas con nombre en inglés, y solo la primera vez. La consola dice cuántos ha encontrado; el informe los lista, y dice dónde no ha buscado y por qué.
- La búsqueda nunca entra en carpetas ocultas o del sistema, enlaces, otros discos, carpetas de red ni carpetas en la nube que no estén en tu ordenador. Solo lista nombres de carpetas: nunca abre un fichero.
- Una clave que solo está en tu historial de git ahora lo dice: «… está en tu historial de git», con el proyecto, el commit y el fichero. Antes enseñaba el fichero tal como está hoy, que git puede estar ignorando, y parecía una falsa alarma.
- Dónde está cada aviso ahora se ve a la primera, en «Qué hacer primero» y en cada fila, no solo en «Detalles técnicos».
- En macOS y Linux, el informe ya no habla de %USERPROFILE% ni del Bloc de notas.
- En Linux, si tu navegador es Firefox instalado como snap y no puede abrir el informe, la consola te dice cómo abrirlo.
- Si tu sistema está en catalán, gallego o euskera, RosmarOps usa ahora el castellano en lugar del inglés, en Windows y Linux.
- El aviso de repositorio con historial largo sale como mucho una vez por revisión.
