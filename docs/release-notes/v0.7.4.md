# RosmarOps v0.7.4

v0.7.4 makes the report shorter: what to do today stays on this computer, and everything else lives in your space.
- The report keeps your situation, what to do first, what is left, how to fix it and your space. Without a space, the rest is in one folded «More information».
- Your space now shows, for each computer, how its score has changed in its latest checks, what changed since the last one, whether the automatic check is scheduled, how each agent works and the analysis details.
- If this computer is not connected to a space, RosmarOps offers to connect it when a check finishes. If you say «Not now», it does not ask again for 7 days.
- The path of this computer's files never leaves it, not even encrypted.
- Each release is now checked on a test computer with 48 projects before you get it.

*En español, más abajo.*

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps.

# RosmarOps v0.7.4 (español)

La v0.7.4 hace el informe más corto: lo que hay que hacer hoy se queda en este ordenador, y todo lo demás vive en tu espacio.
- El informe se queda con tu situación, qué hacer primero, lo que queda, cómo resolverlo y tu espacio. Sin espacio, el resto está en un único «Más información» plegado.
- Tu espacio enseña ahora, de cada ordenador, cómo ha cambiado su nota en sus últimas revisiones, qué ha cambiado desde la anterior, si la revisión automática está programada, cómo trabaja cada agente y los detalles del análisis.
- Si este ordenador no está conectado a un espacio, RosmarOps te ofrece conectarlo al terminar una revisión. Si dices «Ahora no», no vuelve a preguntar en 7 días.
- Las rutas de los ficheros de este ordenador no salen nunca de él, ni cifradas.
- Cada versión se prueba ahora en un ordenador de prueba con 48 proyectos antes de que te llegue.

## Qué fichero descargar
- Windows: `rosmarops.exe`
- Mac con Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac con Intel: `rosmarops-macos-intel`
- `sample-report.en.html` y `sample-report.es.html`: un informe de ejemplo hecho por esta versión en un ordenador inventado. No los necesitas para usar RosmarOps.

¿No sabes qué Mac tienes? Menú Apple > Acerca de este Mac: «Chip» es Apple silicon; «Procesador» es Intel. `SHA256SUMS.txt` solo sirve para comprobar la descarga, y no necesitas «Source code» para usar RosmarOps.
