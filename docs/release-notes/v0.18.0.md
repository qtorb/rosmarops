# RosmarOps v0.18.0

v0.18.0 tells you what you fixed since the last check and which template you already use, and looks deeper at MCP servers.
- What you fixed: the report now says which findings you fixed since the last check. RosmarOps counts a finding as fixed only when it checked the place in full in this run; a project it could not finish is «not checked», not fixed.
- Templates in use: for Claude Code, Grok Build and Cursor, the report says which RosmarOps template your settings already hold, and the next stricter one when there is one.
- MCP servers without a fixed version: RosmarOps tells you when an MCP server starts with npx, bunx, pnpm dlx, uvx, pipx run or docker run and no exact version, so its code can change every time it starts.
- MCP servers approved on their own: RosmarOps tells you when Claude Code has enableAllProjectMcpServers on, so it approves every MCP server a project brings without asking you.
- Keys by their name: in an MCP server's env and headers, RosmarOps now counts a value as a key when the variable's name says so (TOKEN, KEY, SECRET, PASSWORD), even without a known prefix. It never keeps the value.
- Fix: an MCP server you rejected in Claude Code no longer gives MCP findings.
- Fix: a Codex MCP server with enabled = false is no longer counted as loaded.
- Fix: RosmarOps now finds Grok Bot on macOS too.
- Your score can change: the score index moves to version 7 and counts the two new MCP findings.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.
