# RosmarOps v0.12.0

v0.12.0 changes the report: it is now one sheet that fits on one screen, and it adds profiles, a ready-made way to set how each agent works. Your score may change after updating, up or down. Update if you use 0.11.7 or an earlier version.
- The report starts with one sheet: your computer's score, a class from A to D that says how much your agents do without asking you (provisional), the score with factory settings on this computer, and the first 3 findings.
- Five kinds of risk, each with who decides: money, sending out, your keys, running commands and changing files.
- Each finding says how much the agent's score would go up if you change it.
- «Computer profile»: tell RosmarOps what you use your agents for (I write code, I work with documents, Email and calendar, Scheduled tasks) and it proposes a profile for each agent.
- Claude Code has three profiles: Read only, Local development and Unattended. RosmarOps measures the first two on your computer and shows the class and the score before and after. You copy a text and paste it into Claude Code, which shows you the change before saving it. Unattended is a command for your scheduled task. RosmarOps changes nothing.
- Cursor, Grok Build and Grok Bot get guided profiles, with the steps from their documentation, marked «Not measured»: RosmarOps can't measure their effect yet.
- «I accept it»: a finding you accept keeps counting in your score but stops showing as pending. «Dismiss» still makes it stop counting. In the console, «3» dismisses or restores finding 3, and «3a» accepts it.
- A Claude Code `deny` rule for `mcp__*` now covers every MCP server.
- A Claude Code rule in one project's settings now counts only for that project.
- Grok Build's `[permission]` rules are now read, including lists written across several lines.
- Hermes: writing another agent's instruction files that Hermes doesn't protect, such as GEMINI.md, now shows «without asking you» in every approval mode. Hermes's approvals only cover dangerous commands.

## Which file to download
- Windows: `rosmarops.exe`
- Mac with Apple silicon (M1, M2, M3, M4): `rosmarops-macos-apple-silicon`
- Mac with Intel: `rosmarops-macos-intel`
- Linux and WSL, x86-64: `rosmarops-linux-amd64`
- Linux on ARM (for example a Raspberry Pi or an ARM server): `rosmarops-linux-arm64`
- `sample-report.en.html` and `sample-report.es.html`: a sample report made by this version on an invented computer. You do not need them to run RosmarOps.

Not sure which Mac you have? Apple menu > About This Mac: «Chip» means Apple silicon, «Processor» means Intel. `SHA256SUMS.txt` is only for checking the download, and you do not need «Source code» to run RosmarOps. On Linux, make it executable first with `chmod +x rosmarops-linux-amd64`, then run `./rosmarops-linux-amd64`.

# RosmarOps v0.12.0 (español)

La v0.12.0 cambia el informe: ahora es una hoja que cabe en una pantalla, y añade perfiles, una forma ya preparada de decidir cómo trabaja cada agente. Tu nota puede cambiar al actualizar, hacia arriba o hacia abajo. Actualiza si usas la 0.11.7 o una versión anterior.
- El informe empieza con una hoja: la nota de tu ordenador, una clase de la A a la D que dice cuánto hacen tus agentes sin preguntarte (provisional), la nota con los ajustes de fábrica en este ordenador y los 3 primeros avisos.
- Cinco tipos de riesgo, cada uno con quién decide: dinero, enviar fuera, tus claves, ejecutar y cambiar ficheros.
- Cada aviso dice cuánto subiría la nota del agente si lo cambias.
- «Perfil del ordenador»: le dices a RosmarOps para qué usas tus agentes (Programo, Trabajo con documentos, Correo y calendario, Tareas programadas) y te propone un perfil para cada agente.
- Claude Code tiene tres perfiles: Lectura, Desarrollo local y Desatendido. RosmarOps mide los dos primeros en tu ordenador y te enseña la clase y la nota antes y después. Copias un texto y lo pegas en Claude Code, que te enseña el cambio antes de guardarlo. Desatendido es una orden para tu tarea programada. RosmarOps no cambia nada.
- Cursor, Grok Build y Grok Bot tienen perfiles guiados, con los pasos de su documentación, marcados «Sin medir»: RosmarOps todavía no puede medir su efecto.
- «Lo asumo»: un aviso que asumes sigue contando en tu nota, pero deja de salir como pendiente. «Descartar» sigue haciendo que deje de contar. En la consola, «3» descarta o recupera el aviso 3, y «3a» lo asume.
- Una regla `deny` de Claude Code para `mcp__*` cubre ahora todos los servidores MCP.
- Una regla de Claude Code en los ajustes de un proyecto cuenta ahora solo para ese proyecto.
- RosmarOps lee ahora las reglas `[permission]` de Grok Build, también las listas escritas en varias líneas.
- Hermes: escribir ficheros de instrucciones de otro agente que Hermes no protege, como GEMINI.md, sale ahora «sin preguntarte» en todos sus modos de aprobación. Las aprobaciones de Hermes solo cubren las órdenes peligrosas.
