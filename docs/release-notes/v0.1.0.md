# RosmarOps v0.1.0

First public release. Windows only.

RosmarOps reads the configuration of your AI coding agents on this computer and shows what each one can reach: which keys it can read without asking you, whether it can send them out and who decides that (you, another AI model, or nobody), and which agents can change another agent's configuration or instructions. It reads only, writes only to its own folders, and contains no networking code.

## What's in this version
- Evaluates Claude Code and Cursor, each with its own Agent Posture Score out of 100. Detects Cline, GitHub Copilot and Continue, without a score yet.
- Visual report in English or Spanish, in three steps: your situation, what to do first with the exact change, and what's left.
- How your agents work: for each agent, who decides what it does (nobody, another AI model, or you), how far it reaches, and whether that is the factory setting or something you configured.
- Memory between runs: findings that are new, still observed or no longer observed, and agents or MCP servers that are new since the last run.
- Keys saved in git, including in past commits, as findings of their own.
- Export for your AI: a text you can paste into your own agent so it helps you apply the changes, asking you at each step.
- Weekly review: the report gives you the exact command to schedule a review every Friday at 09:00. When it finishes, Windows notifies you, or the report opens if notifications are turned off.
- Integrity: the first setup records a fingerprint of the program and its configuration; later runs ask you before accepting a change, and a scheduled review stops with a red report instead.

## Install
Download `rosmarops-windows-amd64.zip`, extract the whole zip and double-click `rosmarops-run.bat` (or `rosmarops-ejecutar.bat` for Spanish).

## Check the download
```
gh attestation verify rosmarops-windows-amd64.zip --repo qtorb/rosmarops
```
Compare the SHA-256 with `SHA256SUMS.txt`. Building this tag from a clean git clone with Go 1.24.7 (`GOTOOLCHAIN=go1.24.7 CGO_ENABLED=0 GOOS=windows GOARCH=amd64 go build -trimpath -ldflags="-X main.version=0.1.0" -o rosmarops.exe ./cmd/rosmarops`) gives the same `rosmarops.exe`.

## Known limits
- The program is not signed with a code-signing certificate, so Windows SmartScreen may warn you. Use the attestation and the checksum to check it.
- It reads configuration at rest: it does not see what an agent does while it runs, settings kept only inside an app's database or on a vendor's servers, or anything set only in one terminal session. The report states what it assumes and lists what it could not read.
- Declaring a key rotated is your statement: RosmarOps cannot check the revocation at the provider, and the report says so.
- Claude Code's plan mode is not modelled yet: in that mode the report may say «asks you» where auto mode's classifier decides.

See `docs/trust-model.md` for every claim and how to check it.
